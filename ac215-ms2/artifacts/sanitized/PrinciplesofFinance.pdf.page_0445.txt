Many typical applications involve determining if there is a correlation between various stock market indices such as the S&P 500, the Dow Jones Industrial Average (DJIA), and the Russell 2000 index. As an example, suppose we would like to determine if there is a correlation between the Russell 2000 index and the DJIA. Does the value of the Russell 2000 index depend on the value of the DJIA? Is it possible to predict the value of the Russell 2000 index for a certain value of the DJIA? We can explore these questions using regression analysis.
